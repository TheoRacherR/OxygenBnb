# OxygenBnB-app

## Build project

### 1. Get the project locally 
```
git clone git@github.com:TheoRacherR/OxygenBnb.git
```

### 2. Create a .env file with those variables (that you have to fill)
```
DB_TYPE=
PG_HOST=
PG_USER=
PG_PASSWORD=
PG_DB=
PG_PORT=
```

### 3. Finally, Build the project
```
docker compose up --build
```
